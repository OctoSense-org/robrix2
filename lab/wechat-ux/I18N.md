# English and Simplified Chinese

Robrix's main messaging and Moments flows have English and Simplified Chinese
UI catalogs. English is the default. Choose a language on the sign-in screen,
or under **Me → Settings → General → Language**
(**我 → 设置 → 通用 → 语言**). Desktop Preferences also has a Language dropdown.
The choice is local to the Robrix profile, persists across restarts/logout,
and does not change an account or a homeserver setting.

Coverage includes sign-in and SSO labels, the four native tabs, discovery and
joined Spaces, chat actions, room search/media, forwarding, web mini-app
controls, settings/profile editors, Moments and File Transfer. Backend error
details and optional agent/TSP-specific screens may still use English.
Traditional Chinese and automatic OS-language selection are not implemented.

[`src/i18n.rs`](../../src/i18n.rs) owns locale persistence, fallback and
placeholder substitution. Catalogs are
[`en.json`](../../resources/i18n/en.json) and
[`zh-CN.json`](../../resources/i18n/zh-CN.json). English source strings are keys.
Unknown keys fall back to English. Interpolation translates the template once;
inserted values are opaque, including braces and English words that happen to
match catalog keys. Names, IDs, typed drafts and incoming message bodies are
not translated. Chinese dates use a numeric year/month/day and 24-hour time.

Static DSL strings use `#(crate::i18n::tr("Chats"))` and an explicit source
binding such as `i18n_text: "Chats"`. On language changes Makepad rebakes its
DSL; a targeted binding refresh updates labels/placeholders without resetting
inputs. Dynamic labels use `tr`/`format` in their controllers. Never translate
the entire widget tree by matching visible words: a room could be named Chats.

The local [`CachedWidget` compatibility wrapper](../../src/shared/cached_widget.rs)
refreshes the pinned Makepad wrapper's template through its public hook during
rebakes. It retains the actual child and its runtime state. This prevents the
upstream wrapper from treating a rebaked template as an extra child or retaining
a stale source object. The test covers repeated rebakes and child identity.

Apple platforms retain the existing system PingFang SC Regular/Semibold theme
and fallback chain for both languages. Physical iOS layout acceptance remains
separate from the macOS native tests.

## Verification

```sh
python3 tools/wechat-ux/check_i18n.py
cargo test --locked --features agent_chat --lib
cargo build --locked --features agent_chat
# Requires the existing private Palpo Moments fixture; never use personal accounts.
python3 tools/wechat-ux/live/native_i18n.py
```

The checker validates catalog parity and named placeholders and detects missing
literal translation keys. Native journeys exercise login input preservation,
Chinese tabs/settings, an unchanged mixed-language Moments draft, publishing
and independent recipient decryption, language persistence after restart and
desktop switching back to English. Reports and captured frames live in the
ignored `evidence/live/i18n` and fixture run directories.

Validated on 2026-09-20: 692 catalog entries, 868 explicit translation call
sites, 169 passing library tests (one live test ignored), and eight passing
native bilingual checks with zero native errors. All native runs used the same
binary; its hash and run paths are in `evidence/live/validation-i18n.json`.
Reviewed the Chinese Chats, Settings and Moments composer frames at their
original captured resolution. No visual similarity score is claimed.

“One audience per timeline” means a publisher's posts share one membership
list. A post cannot select a different subset in version 1. Adding viewers
does not promise access to all earlier posts; removing viewers cannot recall
previously received content. Private File Transfer is a separate self-chat.
See [Moments ADR](../../docs/adr/0001-matrix-moments.md).
